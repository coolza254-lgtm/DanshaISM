# ตัวคำนวณอ้างอิง (ระบบเดิม)

`engine/` = ตรรกะทั้งหมดของระบบเดิมเป็น JavaScript (รอบเงินเดือน, ยอดบัญชี, หนี้ Ascend PayNext/Extra, SPayLater,
แผนบิล, เช็คก่อนซื้อ, 60/40, พอร์ต) ผ่านการเทียบกับ Apps Script เดิมและ statement จริงแล้ว

**ไม่ใช่โค้ดของแอพ** ใช้เป็นสเปกที่รันได้: ชุดทดสอบ `core/src/test/.../ReferenceTest.kt` รันไฟล์นี้กับตัวคำนวณ Kotlin
ด้วยข้อมูลและเวลาเดียวกัน แล้วเทียบทุกช่องให้ตรงกัน (ต้องมี Node 20+)

- `verify.mjs <data.json> [yyyy-mm-dd] [hh:mm]` — ตัวเลขหลักของวันนั้น (bootstrap, debts, outlook)
- `run.mjs <data.json> <scenario.json>` — รันขั้นตอนอ่าน/แก้ข้อมูลตามลำดับ ใช้ในชุดทดสอบ
- `sample-data.json` — ข้อมูลสมมติ (ไม่ใช่ข้อมูลจริง) ไว้ทดสอบใน CI

ห้ามใส่ข้อมูลจริงในโฟลเดอร์นี้
